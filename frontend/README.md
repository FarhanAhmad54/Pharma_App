# PharmaCore Frontend

React + TypeScript + Vite frontend for Pharma_App.

The UI intentionally follows the supplied PharmaCore reference: near-black enterprise surfaces, thin green-gray rules, monospace operational data, restrained emerald/rose/violet status colors, a fixed left command rail, and dense operational tables.

## Run

```bash
npm install
npm run dev
```

Set `VITE_API_URL` to the FastAPI base URL. Default: `http://localhost:8000/api/v1`.

## Build

```bash
npm run build
```
